二、项目结构
------------
study/
├── AppScope/              # 应用级配置
├── entry/                 # 主模块
│   ├── src/main/ets/
│   │   ├── entryability/  # Ability入口
│   │   ├── pages/         # 6个页面 (Index, LearningSpace, ThreeQuestions, Profile, AIChat, AISettings)
│   │   ├── components/    # 3个自定义组件 (CourseCard, KnowledgeGraph, RadarChart)
│   │   ├── model/         # 5个数据模型 (CourseModel, LearningData, AIService, QuestionModel, MaterialModel)
│   │   └── utils/         # 2个工具类 (Constants, StorageUtil)
│   └── src/main/resources/ # 资源文件
└── 配置文件 (build-profile.json5, hvigorfile.ts 等)

三、关键技术决策
----------------
1. 页面导航: 使用 router.pushUrl/router.back (默认导航方案)
2. 数据模型: 纯内存模型 + AppStorage持久化
3. 知识图谱: Shape组件(Path+Circle)实现而非Canvas,避免复杂绘图API依赖
4. 能力雷达图: Progress(Ring)环形进度条组件组合实现
5. 测评引擎: 基于布鲁姆认知六层级生成模拟题目
6. 大模型接入: OpenAI兼容API接口,支持多种模型(DeepSeek/Qwen/GLM等)
7. 资料管理: 复合知识库模型,支持AI补充+用户上传,按课程维度管理

四、增强功能说明 (2026-06-01 v2.0)

### 4. 学习评价报告增强 (Profile.ets)

六、运行方式
------------
1. 用 DevEco Studio 打开 C:\Users\wyyd\Desktop\study 目录
2. 等待项目同步完成 (自动下载依赖)
3. Tools -> Device Manager -> Local Emulator 启动模拟器
4. 选择设备点击 Run 运行
5. 效果视频可用 Bandicam / OBS Studio 等录制
